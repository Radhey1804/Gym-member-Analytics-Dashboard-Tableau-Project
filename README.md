# Gym Member Analytics Dashboard

An interactive Tableau dashboard designed to analyze gym member demographics, fitness performance, and workout behavior. The dashboard tracks key health and fitness KPIs including average age, average height, average calories burned, and average session duration.

## Dashboard Features

### Key Performance Indicators (KPIs)

* Average Age
* Average Height
* Average Calories Burned
* Average Session Duration (Hours)

### Visualizations

* Butterfly Chart: Member distribution by gender and age group
* Stacked Bar Chart: Member count by experience level (Beginner, Intermediate, Advanced)
* Pie Chart: Workout type distribution
* Stacked Bar Chart: Average fat percentage by experience level
* Heat Map: Calories burned across workout types and experience levels

## Business Insights

The dashboard helps identify workout preferences, fitness performance trends, member demographics, and the relationship between experience levels, body composition, and calorie expenditure. It enables data-driven decision-making for personalized fitness programs and gym member engagement strategies.

* Tableau
